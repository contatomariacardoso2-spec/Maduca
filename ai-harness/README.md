# AI Harness — Maduca

Use este diretório como contexto persistente para agentes de desenvolvimento.

Arquivos recomendados:

- `PRODUCT.md` — intenção e prioridades do produto
- `GUARDRAILS.md` — regras que nunca devem ser quebradas
- `BACKLOG.md` — trabalho priorizado
- `DEFINITION_OF_DONE.md` — critérios de conclusão

O agente deve ler estes arquivos + `docs/TDD.md` antes de alterar arquitetura ou implementar feature nova.

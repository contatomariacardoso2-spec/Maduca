# Definition of Done

Uma feature só está concluída quando:

- fluxo principal funciona no desktop e mobile;
- loading, empty, error e success states foram considerados;
- dados sensíveis permanecem server-side;
- validação ocorre também no servidor quando houver backend;
- nova tabela tem RLS e policy;
- UI mantém linguagem e design system existentes;
- documentação relevante foi atualizada;
- critérios de aceite do TDD foram satisfeitos;
- não houve regressão evidente nos módulos Hoje, Trabalhos, CRM, Portfólio e Financeiro.
